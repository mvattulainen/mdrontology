# Technical Documentation Set

## Definition

**Terminology type:** MDR

The manufacturer-controlled body of documentation described principally in MDR Annexes II and III demonstrating device design, manufacturing, safety, performance and post-market compliance. It is better represented as a structured set of evidence than as one file.
