# Basic UDI Di

## Definition

**Terminology type:** MDR

The primary identifier of a device model/group used as the main key connecting devices with the same intended purpose, risk class and essential design/manufacturing characteristics. It is independent of packaging or production information and serves as a principal access key in EUDAMED.
