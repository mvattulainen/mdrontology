# Post-change battery endurance verification

## Purpose

Defines the type of objective verification evidence required before the proposed battery-cell supplier change can demonstrate the post-change endurance requirement. It is a planned evidence category, not an assertion that acceptable test results already exist.

## Use

The draft compliance requirement points to this evidence type while the change is under assessment. A future approved verification-evidence note may fulfil the type, but only completed results may be connected through `satisfied_by` and used in a release decision.
